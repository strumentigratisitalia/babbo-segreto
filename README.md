# Babbo Segreto

Estrazione del Babbo Natale segreto, gratis e senza registrazione: scrivi i nomi, aggiungi esclusioni e budget, e ogni partecipante riceve il suo link su WhatsApp. Solo lui vede chi ha pescato.

Sito: https://strumentigratisitalia.github.io/babbo-segreto/

## Come funziona

L'estrazione avviene nel browser di chi organizza, con un algoritmo che rispetta le esclusioni (per esempio le coppie). I dati di ogni bigliettino viaggiano solo nel frammento `#` del link, che il browser non invia mai al server: nessun database, nessun dato salvato.

HTML, CSS e JavaScript puri, nessun build. Segnalazioni e correzioni sono benvenute nelle issue.
